# 麻雀計算

麻雀の点数精算・点数表・手牌計算・点差計算・ルール確認ができる、スマホ向けのWebアプリです。`index.html` をブラウザで開くだけで使えます。

## 機能

### 点数精算
- 回ごとの素点を入力すると、順位・ウマ・オカ込みの + / − に変換して表に追加します
- 合計は表の上に表示され、トップのプレイヤー名には 👑 が付きます
- 表は画像として共有できます（プレイヤー名・合計・各回入り）
- 三人麻雀にも対応し、対戦は「過去の対戦」に自動で保存されます（保存はページを開いている間のみ）

### 点数表
- 翻・符を選ぶ「かんたん計算」（親／子・ロン／ツモはタップで切替）
- 親／子のロン・ツモ早見表と、満貫以上の一覧

### 手牌計算
- 牌パレットをタップして手牌を入力し、待ち牌と点数を計算します
- チー・ポン・明槓・暗槓の副露と、赤5に対応しています

### 点差
- 自分と相手の点数、または点数差を入力すると、逆転に必要な最小のあがり（翻・符・点数）を表示します
- 親／子、場のリーチ棒の本数、本場数を設定できます

### ルール
- 麻雀の基本ルールのまとめです
- 「符計算」「役一覧」ボタンで各箇所へ移動できます

## 使い方

`index.html` をブラウザで開いてください。サーバーやインストールは不要で、入力した内容が外部に送信されることはありません。
