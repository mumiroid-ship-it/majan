# 麻雀計算

麻雀の点数精算・点数表・手牌計算ができる、スマホ向けのWebアプリです。`index.html` をブラウザで開くだけで使えます。

## 機能

### 点数精算
- 4人の表に、回ごとの素点を「記入する」ボタンから入力すると、順位・ウマ・オカ込みの + / − に変換して行に追加します
- ウマのデフォルトは10-30、入力欄の上下ボタンは100点刻みです
- 入力はどの順番でもよく、最後に残った1人は合計（四人で100,000点）になるよう自動計算されます
- 合計は表の上に表示され、トップのプレイヤー名には 👑 が付きます
- 行をタップすると入力済みの値で編集でき、右端の × ボタン（確認あり）で1行だけ削除できます
- 「新規」から三人麻雀も選べます（三人用設定：35,000点持ち・40,000点返し、合計105,000点）
- 記入した対戦は「過去の対戦」に自動で保存され、あとから呼び出せます（保存はページを開いている間のみ）

### 点数表
- 翻・符を選ぶ「かんたん計算」が上部にあります
- 親／子のロン・ツモ早見表と、満貫以上の一覧があります

### 手牌計算
- リーチ状態の手牌13枚を、牌パレットをタップして入力します
- 待ち牌を表示し、あがり牌とツモ／ロンを選ぶと、リーチを含む役・符・点数を計算します
- あがり牌や条件を変えると、その場で再計算されます

## 使い方

`index.html` をブラウザで開いてください。サーバーやインストールは不要で、入力した内容が外部に送信されることはありません。
